**`SMART SALES INTELLIGENT SYSTEM`**

This is a beginner-level data analysis project I built using Python and some of its popular data analysis libraries.

The main idea was simple: take a sales dataset, analyze it, create some visualizations, and find useful information from the data.

**`ABOUT THE PROJECT`**

In this project, I worked with sales data containing information about products, regions, categories, and sales.

I used Python to answer questions like:

* How much did we sell in total?
* Which product generated the most sales?
* Which product performed the worst?
* Which region had the highest sales?
* Which category contributed the most?
* What are some important sales KPIs?

The main goal was to practice data analysis on a practical dataset instead of only working with small Python exercises.

**`WHAT I FOUND`**

`PRODUCT PERFORMANCE`

The **Laptop** had the highest total sales, generating **₹2,64,000**.

The **Mouse** had the lowest total sales at **₹15,480**.

This was one of the first things I looked at because it gives a quick idea of which products are contributing the most to revenue.

`REGINOL SALES`

The **South region** had the highest sales with **₹2,99,400**.

The **East region** had the lowest sales with **₹1,42,250**.

This helped me compare how the business was performing across different regions.

`CATEGORY PERFORMANCE`

The Electronics category performed the best, with total sales of **₹6,90,000**.

So, electronics products were responsible for a large part of the total revenue in this dataset.
